# Игровая полка для логопеда

Адаптивный каталог логопедических игр и заданий на чистых HTML, CSS и JavaScript — без сборки и внешних зависимостей. Автор сайта: Logoped_Ada.

## Запуск

Откройте `index.html` в браузере. Для локального HTTP-сервера из корня проекта запустите:

```powershell
python -m http.server 8000
```

Затем перейдите на http://localhost:8000.

## Игры каталога

«Звуковая охота» — интерактивная игра в `games/zvukovaya-ohota/index.html`. Она использует категорию «Звуки Ш, Ж, Ч» и открывается по ссылке из каталога. Демонстрационные карточки удалены; в каталоге показываются только реальные игры.

Чтобы добавить игру, поместите её файлы в отдельную папку, затем добавьте объект с названием, категорией, описанием и относительным адресом игры в массив `games` файла `script.js`. Категории фильтра: «Чтение», «Звуки С, З, Ц», «Звуки Ш, Ж, Ч», «Звук Р», «Звук Л» и «АГ».

Каталог включает поиск по названию, жанру и описанию, фильтры категорий, фокус в поиске клавишей `/` и очистку поискового поля клавишей `Escape`.
