# Игровая полка для логопеда

Адаптивный каталог логопедических игр и заданий на чистых HTML, CSS и JavaScript — без сборки и внешних зависимостей. Автор сайта: Logoped_Ada.

## Запуск

Откройте `index.html` в браузере. Для локального HTTP-сервера из корня проекта запустите:

```powershell
python -m http.server 8000
```

Затем перейдите на http://localhost:8000.

## Игры каталога

«Звуковая охота» — интерактивная игра в `games/zvukovaya-ohota/index.html`. Она использует категорию «Звуки Ш, Ж, Щ, Ч» и открывается по ссылке из каталога. Демонстрационные карточки удалены; в каталоге показываются только реальные игры.

«Приключение на звуки» — отдельная 2D-игра в `games/zvukovoe-priklyuchenie/index.html`. Игрок исследует тематические иллюстрированные локации: шуршащий сад, жужжащую поляну, чердак и озеро — и определяет, есть ли заданный звук в названии предмета.

Чтобы добавить игру, поместите её файлы в отдельную папку, затем добавьте объект с названием, категорией, описанием и относительным адресом игры в массив `games` файла `script.js`. Категории фильтра: «Чтение», «Звуки С, З, Ц», «Звуки Ш, Ж, Щ, Ч», «Звук Р», «Звук Л» и «АГ». Внизу каждой игровой страницы указывайте автора `Logoped_Ada` и ссылку для сообщения об ошибке на `musalimova.ad@icloud.com`; это правило действует для всех новых игр.

Каталог включает поиск по названию, жанру и описанию, фильтры категорий, фокус в поиске клавишей `/` и очистку поискового поля клавишей `Escape`.

Для проверки фонемного подбора и основных состояний 2D-игры выполните `node --test games/zvukovoe-priklyuchenie/game.test.js`.
