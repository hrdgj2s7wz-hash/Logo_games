# Звуковая охота

Браузерная игра помогает тренироваться находить звуки Ш, Ж и Ч в названиях предметов.

Откройте `index.html` в современном браузере и выберите один из трёх уровней-сундуков. Нажимайте на предметы, чтобы услышать их названия. На каждом уровне семь подходящих предметов из двадцати; за каждую находку игрок получает золотую монету и за прохождение уровня — пять звёздочек. После всех трёх уровней и сбора 21 монеты и 15 звёзд появится финальная награда. Её можно закрыть, открыть снова с экрана выбора или начать игру заново, сбросив общий прогресс.

В каждом уровне также есть задание на определение положения звука в слове по картинке и звучанию. После последнего вопроса кнопка-сундук возвращает к выбору уровня.

Для озвучивания используется встроенный Web Speech API. Доступность голосов зависит от браузера и операционной системы.

Прогресс сохраняется в локальном хранилище браузера. Автор: Logoped_Ada. Для сообщения об ошибке используйте ссылку внизу страницы.
