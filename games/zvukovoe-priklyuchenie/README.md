# Приключение на звуки

Отдельная браузерная 2D-игра на чистых HTML, CSS и JavaScript, без установки зависимостей. Игрок выбирает один из четырёх звуков — Ш, Ж, Ч или Щ — и исследует плоскую иллюстрированную локацию с восемью предметами. Содержимое соответствует месту: в саду — шишка, шмель и грибы; на поляне — жуки, бабочки и цветы; на чердаке — часы, сундук и старые книги; у озера — рыбы, камыши, лодка и берег. В каждом наборе есть слова с искомым звуком и без него. Нужно подойти к предмету, прослушать его название и определить, есть ли в нём выбранный звук. После ответа игра показывает подсказку и автоматически продолжает исследование через короткую паузу; за верный ответ начисляется звезда.

## Запуск

Откройте `index.html` в современном браузере или запустите HTTP-сервер из корня проекта:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000/games/zvukovoe-priklyuchenie/`.

На компьютере перемещайтесь стрелками или клавишами WASD; на телефоне используйте экранные кнопки со стрелками. Нажмите «На весь экран» в игровом меню, чтобы развернуть сцену, и нажмите «Обычный экран» или клавишу Escape для выхода. Нажмите на предмет рядом с персонажем, чтобы открыть задание. Озвучивание использует встроенный Web Speech API; если браузер его не поддерживает, слово можно прочитать на экране и произнести вслух.

## Проверка

Запустите тесты фонемного подбора, игровых данных, моделей и переходов раунда из корня проекта:

```powershell
node --test games/zvukovoe-priklyuchenie/game.test.js
```
